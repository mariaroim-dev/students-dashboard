# Students Dashboard

Educational JavaScript project: a simple students dashboard application with a frontend and a local backend server.
Focus: working with API requests, dynamic UI rendering, and application logic in vanilla JavaScript.

## Project Structure
This repository contains two parts:
- `frontened/` — frontend (UI)
- `backend/` — backend server (API)  
- `package.json` — scripts and dependencies

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Node.js / npm (local backend server)

## Features
- Dynamic rendering of students data (data comes from the backend API)
- CRUD-like interactions (depending on the course task: add/edit/delete/filter/sort)
- Client-side logic: DOM manipulation, events, UI updates without reload
- API requests to a local server

## How to Run Locally

### 1) Install dependencies
npm install

2) Start backend server
Open one terminal and run backend (use the script from package.json):

npm run server
# or
npm run backend
# or
npm run start

3) Start frontend
Open a second terminal and run frontend (if a dev server is used):

npm run dev
# or
npm run start
